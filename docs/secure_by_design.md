## Principio

La seguridad se integra desde el diseño, no se añade al final.

## Aplicación al repositorio

Cada laboratorio debe definir:

- activos;
- amenazas;
- superficies de ataque;
- controles;
- riesgos residuales;
- evidencias.

## Criterios

```text
NO CUMPLE si:
- No hay threat model.
- Hay secretos reales.
- Se presentan mitigaciones sin test.
```
