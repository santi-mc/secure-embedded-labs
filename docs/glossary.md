## HAL

Hardware Abstraction Layer. Capa que encapsula el acceso al hardware.

## BSP

Board Support Package. Adaptación específica a una placa concreta: pinout, buses, alimentación, consola y periféricos.

## Threat Model

Modelo de amenazas que identifica activos, superficies de ataque, adversarios, riesgos y mitigaciones.

## SBOM

Software Bill of Materials. Inventario de componentes y dependencias de software.

## PSIRT

Product Security Incident Response Team. Proceso/equipo para gestionar vulnerabilidades de producto.

## Secure Boot

Mecanismo para verificar la autenticidad e integridad del firmware antes de ejecutarlo.

## Flash Encryption

Cifrado de la memoria flash para proteger firmware y datos persistidos frente a lectura física.
