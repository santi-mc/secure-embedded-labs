## Alcance

Este repositorio contiene laboratorios educativos de seguridad embebida. Algunas vulnerabilidades son intencionadas y están documentadas dentro de cada laboratorio.

## Reporte de vulnerabilidades

Si encuentras una vulnerabilidad no intencionada en un laboratorio, repórtala mediante un issue o el canal privado que se defina cuando el repositorio sea público.

## Vulnerabilidades intencionadas

Las vulnerabilidades intencionadas deben estar marcadas explícitamente como parte del objetivo didáctico.

## Secretos

No se deben subir secretos reales al repositorio.
