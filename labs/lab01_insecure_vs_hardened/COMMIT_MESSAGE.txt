fix(lab01): evitar spam de consola cuando stdin no tiene datos

Corrige el bucle de consola del LAB 01 para que la ausencia temporal de
datos en stdin/USB Serial-JTAG no genere eventos `console_warning` de forma
continua.

Cambios principales:
- añade el estado ConsoleReadStatus::NoData
- diferencia ausencia de datos de línea válida o línea demasiado larga
- aplica un backoff de 50 ms en la HAL de consola stdio
- evita registrar warnings repetitivos en el bucle principal de comandos
- mantiene los logs de errores reales de consola para estados inesperados

Motivo:
En ESP-IDF/USB Serial-JTAG, fgets puede devolver nullptr cuando todavía no
hay línea disponible. Tratarlo como EOF real provocaba un log cada iteración,
haciendo inutilizable el monitor serie.

Validación requerida:
- python tools/repo_quality_gates/run_static_repo_gates.py
- python labs/lab01_insecure_vs_hardened/tools/run_static_gates.py
- idf.py build
- idf.py flash monitor

- NO VALIDADO en build ESP-IDF real dentro de este entorno.
- NO CUMPLE como firmware de producción.
