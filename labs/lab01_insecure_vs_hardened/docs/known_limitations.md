# LAB 01 — Limitaciones conocidas

## Índice

- [Objetivo](#objetivo)
- [Limitaciones](#limitaciones)
- [Estado](#estado)

## Objetivo

Declarar limitaciones para evitar sobredimensionar el laboratorio.

## Limitaciones

```text
- No implementa red, MQTT ni TLS.
- No implementa NVS ni almacenamiento seguro.
- No implementa OTA.
- No activa Secure Boot ni Flash Encryption.
- No es firmware de producción.
- Usa secretos ficticios de laboratorio.
- Usa C++ estándar en consola interactiva; no es ruta hard real-time.
```

## Estado

```text
CUMPLE:
- Limitaciones declaradas.
```
